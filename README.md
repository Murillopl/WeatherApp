# WeatherApp 🌤️

## 📌 About the Project

**WeatherApp** is an Android weather application built with **Kotlin** that displays real-time weather data for a given city.  
The app fetches weather information from a public API (e.g., OpenWeatherMap) and presents it with a clean and user-friendly interface.

---

## 🚀 Features

✔️ Search weather by location  
✔️ Display current temperature, weather description, humidity, wind, and more  
✔️ Clean and simple UI  
✔️ Real-time weather updates  
✔️ Built with modern Android development tools and Kotlin

## 🧠 Technologies Used

- **Kotlin** – Main programming language  
- **Android SDK** – Core Android APIs  
- **Retrofit / Networking** – Fetch weather data from API  
- **JSON Parsing** – Handle API responses  
- **Gradle** – Build system
